参数配置详细说明

对应「网关模型管理」页的参数配置卡 · 返回控制台 ↩ · 数据来自内置模型目录（官网逐条取证）

一 · 参数配置卡怎么用
表格里填的值 = 网关随请求发出去的值
厂商公布了缺省值的参数，新建模型时已自动带入官方默认；改了值就按你改的发，留空就发厂商默认。
优先级：工具调用传参 > 网关设置 > 厂商默认
Trae / Cursor 等工具在请求里自己带的参数最优先；请求没带才用这张卡里的值；卡里也没写就用厂商默认。
只对对话（chat）生效
图像生成端点不注入任何参数。
「恢复官方配置」按钮
一键把全部参数还原为厂商官方默认，你改过的值与手动添加的自定义参数会被覆盖。
二 · 网关自动代发的 2 个参数（参数卡里改不了）
max_tokens（最大输出）
你没有在参数卡里填写输出上限时，网关会按「实际承接这条请求的账号自己」的最大输出代发——防止超出某个账号的限额被厂商拒绝。整池对外承诺的上限以模型详情页「网关承诺（合并规格）」为准。想自己定：在参数卡写 max_tokens，写了网关就不再代发。
thinking / reasoning_effort（推理档位）
控制模型是否深度思考、思考多深。资源池里哪一行设了默认就按那一行代发；都没设就不代发，用厂商自己的默认行为。想设置：模型详情页「资源池」每行右侧的推理档位下拉。
共同规则
工具请求里明确带了这两个参数时，以请求为准，网关不覆盖。
三 · 常见参数是什么意思（通用概念）
温度 temperature
越高回答越发散有创意，越低越确定、保守。写代码、抽取类任务建议 0~1，写作可调高。
核采样 top_p
另一种控制随机性的方式（只从累计概率前 top_p 的候选词里挑）。一般和温度二选一调，不建议同时大改。
top_k / min_p
同样是收窄候选词范围的采样参数，不同厂商支持情况不同，以各模型档案为准。
最大输出 max_tokens
本次回答最多生成多少 token，到上限就停。注意部分厂商把思考过程的 token 也计入上限。
停止词 stop
生成到这些词就停，多个值用英文逗号分隔；各厂商有条数上限（见各模型档案）。
存在惩罚 presence_penalty / 频率惩罚 frequency_penalty / 重复惩罚 repetition_penalty
减少重复内容的力度。部分厂商已废弃或忽略这些参数，设了不生效。
随机种子 seed
同样输入想复现同样输出时用；部分厂商已不保证确定性。
生成条数 n
一次生成几条候选回答。
采样开关 do_sample
关掉采样 = 贪心输出（最确定）；智谱模型设为 false 时温度与 top_p 一起失效。
max_completion_tokens
较新厂商替代 max_tokens 的键名（含思考 token），含义相同。
档案四档含义： 可设 正常生效 已废弃 厂商标注弃用（网关不代发它的默认值） 被忽略 设了也不生效 会报错 传非默认值直接被拒绝
