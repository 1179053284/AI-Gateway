## 需求落地对照

| # | 用户反馈 | 落地 |
|---|---|---|
| 1 | 内容区左侧页面结构完全不对 | 重写页面布局：左子侧栏固定 248px + 右配置区 flex 撑满；页面接管 `.content` 留白（margin 抵消 + 断点适配 1280/768），高度精确等于可视区（`calc(100vh - 60px)`），结构在 1440/1100 两宽度下实测正确（子侧栏恒 248px） |
| 2 | 去掉「该厂商全部 Key 共用」 | 提示随接入配置卡一并移除 |
| 3 | 接入形式/Base URL 未设置前显示，设置后不显示且不可修改 | 接入配置卡仅在 Base URL 未设置时渲染（现网数据均已设置 → 不显示）；设置后界面无编辑入口（仅配置文件可改） |
| 3(续) | 「一组 Key + 所属账号（选填）= 一条资源，可添加多组」放到标题右侧右对齐 | Key 卡头 `space-between`：标题左、提示右对齐 |
| 3(续) | Key/账号参考接入形式样式；支持删除；删除 icon 前加开关控制该 Key 是否投用 | 每组一行：标签式字段（Key 值 + 眼睛 / 所属账号）+ **「启用」开关（= resources[].enabled，停用退出调度）**+ 删除（确认级联映射）；行随停用降透明度 |
| 4 | 模型列表去掉行内左右边距；下拉展开样式调整（icon 太靠右） | 行 `padding:0`；系统模型下拉固定 **300px**（箭头贴近文字，不再远离）；删除 icon 留 12px 右距；行间 1px 分隔线 |
| 5 | 右侧配置板块撑满（左右边距 = 上边距 12px） | 移除 980px 上限，主区 `padding:12px` |
| 6 | 有滚动条时底部多出一块空白 | 页面接管留白方案：`#rv-wrap` 高度精确填满（实测 `contentScroll === contentClient === 880`，**无滚动溢出、无底部空白**），滚动移入配置区内部 |
