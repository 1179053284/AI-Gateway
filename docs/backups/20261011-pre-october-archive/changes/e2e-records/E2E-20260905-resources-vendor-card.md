## 根因复盘（同日，用户连续反馈「样式还是错位」后定位）
- **用户浏览器标签页长期未刷新，运行的是多轮之前的旧脚本**：ES 模块仅页面加载时拉取一次，hash 路由不重载 JS——旧界面 + 服务端新文件混搭，导致「改了看不见、去掉了还在」的连续错位（用户截图中 Plan 值块独立卡 = 4 轮前旧布局）。
- 服务端核验：resources.js / main.js / base.css / index.html 四文件「磁盘 = 线上」MD5 逐字节一致；无痕实例渲染 = 最新代码（pills 在头卡内等全部断言通过）。
- **机制根治**：main.js 界面文件更新自动刷新（快照 10 个界面文件文本，20s 轮询，变化 → 提示 3s 后自动 reload）。实测：修改 base.css → 26s 内页面自动重载两次（标记变量消失验证）；pytest 187/187。
- 用户侧动作：**旧标签页关闭重开（或强刷一次）获得带轮询的新 main.js，此后无需手动刷新**。
