## 改动清单
- `model_gateway/web/static/js/pages/models.js` 全量重写（纯前端，唯一改动文件）：
  - 版式 = 「模型资源」页同款骨架：左 `subnav` 248px + 右撑满配置区（内部滚动，margin 抵消 content 留白带断点）；
  - 左列 = 厂商 `group-card`（卡头 `mark-sm` 厂商首字 + 厂商名；行 = `mode-btn` 系统模型 ID + `.dot`）；分组口径同资源页 `vendor → preset → 单条`；模型出现在其映射引用的**每个**厂商卡（多厂商映射 = 多卡出现，仅视图分组，存储不变）；无有效厂商引用的模型归「未映射」区；
  - 圆点 = `models[].enabled` 纯状态指示（绿=生效中/灰=未开启），不再承担点击启停（对齐 frontend-spec §6 交互范式⑥「圆点数据态、开关操作态」；启停操作在详情头卡「禁用/启用」按钮）；
  - 右侧 = 现有配置整体迁移，零新增字段：头卡（logo 块 + 模型名 + 端点/启停徽章 + 副行 + 禁用/启用 + 删除）→ 基本属性卡（端点下拉 + 分组输入，Q20-②）→ 资源池卡（序号 + 资源备注 + 厂商徽章 + /厂商模型 + effort（仅 chat）+ ↑↓ + 移除，顺序 = 优先级）；
  - 交互从「保存配置」二段提交改为**操作即保存（D3，同资源页）**：变更直接 PUT + toast，失败提示并以服务端最新配置重渲染；移除映射/删除模型走确认弹窗；
  - 本页定位不变（Q19-② 总览微调，映射创建在资源侧；Q18-④ 无任何调度参数）。
