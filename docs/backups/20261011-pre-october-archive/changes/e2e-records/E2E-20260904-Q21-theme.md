## 2. E2E-20 追加核验（Q21 视觉升级，第⑨项）

### 2.2 主题按钮 / 菜单渲染（DOM 实测）

- 顶栏右侧（调用地址之后、重载配置之前）出现主题按钮 `#theme-btn`（太阳线性图标）；点击弹出 `#theme-menu`，三项：`浅色`（data-theme-mode=light）/ `深色`（dark）/ `跟随系统`（system）。
- 无 localStorage 时默认 `mg-theme=null` → 按「跟随系统」解析：本机 `prefers-color-scheme: light` → `html[data-theme="light"]`。

```
INIT {"theme":"light","stored":null,"sysDark":false,"hasBtn":true}
MENU_OPEN true
```

### 2.3 深色切换 + 持久化（刷新验证）

点击「深色」后：

```
DARK {"theme":"dark","stored":"dark","on":"dark",
      "bodyBg":"rgb(19, 20, 25)","sideBg":"rgb(22, 24, 30)","sideText":"rgb(232, 234, 239)"}
```

- `--bg:#131419`、`--side:#16181e`、`--side-strong:#e8eaef` 与实测色值一致（令牌命中）；
- 菜单高亮项 `button.on` = dark；
- **刷新页面后仍为深色**（`RELOAD {"theme":"dark","stored":"dark"}`）→ localStorage 持久化生效。

### 2.4 浅色切换

```
LIGHT {"theme":"light","stored":"light",
       "bodyBg":"rgb(244, 245, 247)","sideBg":"rgb(255, 255, 255)","cardBg":"rgb(255, 255, 255)"}
```

- `--bg:#f4f5f7`、`--side:#ffffff`、`--surface:#ffffff` 与实测一致；浅色侧栏为白色（aionui 清爽风）。

### 2.5 跟随系统实时联动（Emulation 模拟系统配色）

```
SYSTEM_DARK_EMULATED  {"theme":"dark","sysDark":true}
SYSTEM_LIGHT_EMULATED {"theme":"light","sysDark":false}
```

- 选中「跟随系统」后，模拟系统深色偏好 → `data-theme=dark`；改回浅色 → `light`（`matchMedia` 监听实时生效）。

### 2.6 菜单外点关闭

```
MENU_CLOSE_ON_OUTSIDE true
```

## 4. 遗留与说明

- 主题切换为**纯前端**：CSS 变量 + `html[data-theme]` + localStorage，无接口、无配置变更，Q20 及之前全部功能不受影响（全量回归 187 通过佐证）。
- ego-browser（Chromium）本次环境连接挂起（历史会话反复出现），证据改用**系统 headless Chrome 152 + CDP**（`Page.captureScreenshot` 成功取证，口径更硬）；如需 ego-browser 复核可在正常环境重跑。
- 「跟随系统」在无存储的首次访问默认启用；显式选择后以 localStorage 为准。
- 组件保持**小圆角**（按钮 8px / 卡片 12px / 胶囊仅徽章、开关、状态点），未采用 aionui 的 100px 全圆角（用户裁定保留小圆角）。
