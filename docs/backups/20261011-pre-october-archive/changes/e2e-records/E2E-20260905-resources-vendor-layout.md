## 落地结构（对照模板 template-providers.html）
- 左子侧栏 248px：分组「已接入厂商」+ anchor-item 厂商行（首字 mark + 名称 + 启用状态点）+ 底部「＋ 新增资源」（side-add）
- 右主区 max-980 居中：
  - **头卡**：logo 块 + 厂商名行内编辑（✏，Enter/失焦提交改写该厂商全部资源 `vendor`）+ 副标「Key 及关联账号 · N 组 Key · M 个模型映射」+ 右侧 [禁用/启用]（整厂商）+ [🗑 删除厂商]（确认弹窗列明 N 组 Key 与受影响系统模型，级联清理映射）
  - **接入配置卡**：接入形式 + Base URL（厂商全部 Key 共用，change 即保存）
  - **Key 及关联账号卡**：每组一行 = Key 值（服务端脱敏 + 小眼睛 `?reveal=1` 明文/收回）+ 所属账号（选填）+ 🗑（确认后级联删资源与映射）；「＋ 添加 Key」草稿行填写 Key 失焦即落为新资源（`@new-*` → 服务端生成 `res-` id，继承厂商接入字段）
  - **模型列表卡**：表头「供应商模型ID | 系统映射模型ID | 操作」；映射集 = 厂商各资源**并集**，行内改名/换目标/删除同步应用至该厂商全部资源；「＋ 添加模型」草稿行双字段齐全即保存；系统模型单选下拉（停用标注，无就地新建）
- 操作即保存（D3 延续）；无提示信息；无 Claude 映射卡
