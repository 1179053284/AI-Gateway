### 3.5 我自己判断错的一个假设（**已自我否决，记录以示核验有效**）

**假设**：`maxOutputTokens.map` 的 4 种写法里，3 种用**单引号** `'max_tokens'`、15 种用双引号 → 如果解析器只认双引号，这 3 条会在加载期抛错，**是 ZCode 的一个潜在 bug**。

**核查结果**：**假设不成立。** `packages/model-option-map/src/tokenizer.ts:32` 明确写着：

```ts
if (character === "'" || character === '"') {
```

→ **单双引号都接受**。所以这只是一处**写法不统一的数据质量问题**，不是缺陷。

**这个错误假设的价值**：它反过来证明了另一件事 —— **纯手写配置会漂移**（同一个方言两种写法），所以"规范化 + 校验"是必需的，不能靠自觉。这条已写进 `06` §3·不足 4。
