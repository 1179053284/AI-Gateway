# 模块事实表（需求落地沉淀）

> 本目录 = **AI 工作记忆**（需求锚点/接口/坑位，快变）；设计真相（是什么/为什么）在 `docs/specs/**`（慢变）。冲突以 specs 为准。
> 每完成一个模块（配置系统 / 供应商通道适配器 / 调度器 / API 端点 / 管理 UI …）在此沉淀一页**已验证**事实，后续同模块改动直接读表，不再全量重新取证。禁止预填未验证内容；每条标注证据来源（实测输出 / 需求文档路径）。

## 模板

```markdown
# 模块名

## 需求锚点
- PRD 条目 / 文档路径:行号

## 接口与结构
- 类/函数签名、配置键、边界语义

## 已知坑（本模块特有）
- 现象 → 根因 → 修复方向（日期）

## 证据
- 实测命令 / 输出片段 / 测试断言路径

## 测试面（防重复验证）
- 已验证点 / 命令 / 上次通过日期 / 已知失效场景
```
