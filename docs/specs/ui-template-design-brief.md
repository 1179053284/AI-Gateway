## 1. 背景与目标

### 1.1 现状

| 项 | 现状 |
|---|---|
| 已定版页面 | 7 页（总览 / 模型资源 / 资源池设置 / 数据看板 / 请求日志 / API 接入 / 系统设置），全部已按 frontend-spec v2.10 落地 |
| 已有模板 | **仅 2 个**：`template-providers.html`（骨架 A）· `template-skills.html`（骨架 B） |
| 骨架选型表 | 4 类（A 子侧栏双面板 / B tab+列表 / C 数据观测 / D 工具页），**C 与 D 无模板** |
| 缺口 | ① 模板数量少，新页面只能"从零组装"；② **多页签（页签条 / 主从内页签）无任何范式**；③ 抽屉、向导、批量任务、代码查看器、实时流等**通用形态完全空白** |
| 未来需求 | `docs/research/` 已产出 P0–P2 路线（下游接入向导、平台账号授权、参数方言/站点维度、模型清单下发、上游形态合规分层…），**这些页面目前没有任何模板可套** |

### 1.2 目标

把模板库从 **2 个 → 14 个**，做到"**新页面 = 选模板 + 换数据，不需要从零组装**"，并**预先覆盖**后续需求清单中的页面形态。

### 1.3 成功标准

- 新页面开发不再出现"规范里没有、自己发明"的组件（新增组件全部来自本文 §8 的清单）。
- 后续需求（§7 映射表）落地时，**每一行都能指到某个模板**，无需临时设计。
- 全部模板在**浅色 + 暗色**双主题下截图通过，且与既有 7 页并排对照无可见偏差。

## 2. 设计约束（硬约束，不可突破）

> 全部取自 `frontend-spec.md` §1/§7 与 `design-spec.md` §1。**违反任一条即判定不合格，不进入评审。**

### 2.1 令牌与色

- 只允许使用 CSS 变量令牌（`--bg/--surface/--content/--border/--text*/--brand/--on-brand/--ok/--err/--warn/--cool/--g-coding/--seg-bg/--shadow*/--radius*/--mono` 等）。**禁止任何硬编码色值**。
- 唯一例外：`.code-block` 恒深底 `#161a26`（代码展示惯例，双主题不变）。
- 新增语义色（如"合规/受限"）**必须**从既有色板借用（`--warn` 橙 / `--err` 红 / `--cool` 蓝），不得新增色值。

### 2.2 尺寸与间距

| 项 | 值 |
|---|---|
| 间距 | 仅 `4 / 8 / 12 / 16 / 20 / 24`；**页面纵向块间距一律 12px** |
| **圆角** | **仅令牌 `--radius-xs 4` / `--radius-sm 6` / `--radius-md 8` / `--radius-lg 10` / `--radius-full`（v2.12 统一，4 级 + 胶囊）。禁止裸写 px 或 `50%`** |
| 按钮 | `.btn` h-36 · `.btn-primary` h-36 · `.btn-lg` h-44 · `.btn-sm` h-30 · `.icon-btn` 32（sm 28 / lg 36）· 圆角一律 `--radius-md`(8) |
| 输入 | 表单 `.form-row` input h-44 `--radius-md`(8)；行内 `.in` h-36 `--radius-md`(8)；搜索 `.input-group` h-44 `--radius-md`(8) |
| 开关 | `.switch` 40×24 `--radius-full`；状态圆点 `.dot` 8×8 `--radius-full` |
| 图标块 | `.mark-sm` 20×20 `--radius-sm`(6)；`.logo-block` 40×40 `--radius-md`(8)；`.metric-ico` 38×38 `--radius-md`(8) |
| 卡片 | **`--radius-lg`(10)**（v2.12 由 13px 收紧）· padding 12px · `--shadow-card` · 无边框（暗色补 1px 边框） |
| 表格卡 | `.card.flush` + `.card-head.inset`，`.tbl` 直贴 |
| 页签段 | `.tab` h-32 `--radius-sm`(6) px-12 12px/700；容器 `.tabs` `--radius-md`(8) `--seg-bg` p-4 |
| 弹窗 | 560px（表单）/ 800px（设置）· **`--radius-lg`(10)** · 遮罩 `rgba(15,18,25,.45)` + blur 3px |

**列表/表格对齐（v2.12 用户指示「所有列表类样式，表头的标题和下方表的数据，一定要左对齐」）**：
- `.tbl` 内 **所有 `th` / `td` 一律 `text-align: left`**（含数字列 `.num`）。原「数字列右对齐 + tabular-nums」的惯例已废除，表头文字与数据文字共用同一条**左**边缘，全表形成左侧直线。（`tabular-nums` 保留，便于纵向比对位数。）
- 唯一的居中例外：`.tbl .sel`（行首复选框列）与 `.tbl td.exp`（展开箭头列）—— 二者**无表头文字**，属工具列而非"标题/数据"。
- **平铺列表（非 table）**：列必须成直线。`.list-row` 若用 flex 自动宽度，前置弹性列会随内容变化把后列推走（T-16 实测第 3~7 列漂移最大 72.6px）。**解法：`display: grid` + 固定轨道**。注意 `max-content`/`auto` 是"每个 grid 容器内部"解析的，每行一个 grid 容器时仍会漂移 —— 必须用**固定 px 上限（`minmax(0, Npx)`）或 fr 比例**，见 `template-premium-list.html` 的 `#list-card .list-row` 规则。

**同行控件必须等高（v2.12，用户指出「这种元素高度没对齐的低级错误也不应该出现，即使是模板」）**：
- 同一 flex/grid 行内的控件（按钮 / 输入框 / 分段 tab / 开关）可视高度必须一致，**容差 ≤1px**。核对方式：按"是否同一行"分组（折行容器跨行不可比）、`.form-row` 取**内部控件**而非整块，再比实高与中线。
- 已定型的两档行高，**不得混用**：
  - **表单 / 筛选行 = 44px** —— `.input-group` / `.form-row input` / `.in` / `.btn-lg` / `.filter-grid .tabs`（`.tabs` 在筛选行内补到 44px，段仍 32px 居中留白）
  - **紧凑工具条 = 40px**（与分段 tab 同排）—— `.tabs` / `.page-head .input-group` / `.page-actions .input-group`
- 反向约束：`.filter-grid` 内的按钮**必须** `.btn-lg`（44px），不得用默认 `.btn`（36px）；`.page-head`/`.page-actions` 内的搜索框降为 **40px**（原 44px 与 40px tab 混排差 4px）。
- **`.tab` 标签禁止换行**：`.tab` 必须带 `white-space: nowrap` + `flex: none`，段按内容定宽；行宽不足时由**行**负责换行/滚动，**不得**让标签折成两行（"默认"→"默/认"）。实测该缺陷曾出现在 T-16 工具行 10 个状态/主题 tab 上。
- **检测口径提醒**：判"文字折行"必须**逐文字节点**统计行数（同一节点跨多行才算），且同一行内不同字号的内联片段 `top` 会差 1~2px，需按 ~4px 容差聚类。按"元素内所有文字节点合并"或"元素 box 行数（`getClientRects()` 量 button）"都会误报/漏报。

### 2.3 字号体系（穷举，无其他值）

`19px/700`（指标值）· `18px/800`（价格）· `16px/800` · `15px/800`（页标题）· `14px/800` · `13.5px`（**卡片标题**，见 design-spec §1.3）· **`13px`（基准：名称/按钮/输入/表格）** · `12.5px`（**.mono 长 ID / Key / 协议列**，见 §6 T-03）· `12px`（辅助/徽章/tab）· `11px`（微）· `10px/900`（mark 字母）。

> **v1.2 补记**：`13.5px` 与 `12.5px` 原未列入本穷举表，但二者在既有真相源中均已定：`13.5px` 见 `design-spec.md:153`（卡片标题 13.5px extrabold），已过审 P0 六件套有 17 处在用；`12.5px` 见 `base.css` 四处定义 —— `.btn-sm`(198) / `.tbl .mono`(287) / `.in.mono`(339) / `.key-row .kval`(416)，以及本文 §6 T-03 的协议列 `.mono` 12.5px。经复核判定为**本表遗漏**而非实现违规，故补入并限定用途：**`13.5px` = 卡片标题；`12.5px` = `.btn-sm` 与 mono 类（长 ID / Key / 协议 / 凭据值）**。二者**不得**移作正文或表格基准字号（那是 `13px`）。
字体：**Inter（本地内置，数字/西文）+ PingFang SC / 微软雅黑（CJK 回落）**；数字一律 `font-variant-numeric: tabular-nums`。
**指标值 CJK 混排**：值内中文段必须包 `.cv`（`.86em`）与数字视觉等高。

### 2.4 图标

- **唯一图标库：Lucide 0.555.0**（官方 path 内联，禁止手绘）。
- 属性契约：`viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"`。
- 尺寸：导航 16（sw 2.1）· 动作 14（sw 2）· logo 块 20 · 药丸 check 12。
- 颜色只吃 `currentColor`。

### 2.5 技术形态（影响设计交付形式）

- **无构建**：原生 ES Modules + 手写 CSS。**模板必须是单个 `.html` 文件**，CSS 内联在 `<style>`（仅用于演示），类名与既有模板保持一致。
- **禁止任何 CDN / 外链资源**（含 Google Fonts、图标 CDN、图片外链）。
- **禁止导出数据功能**（2026-09-06 用户指示，全站移除）。
- **禁止**：原生 `<select>` 箭头（用自定义下拉）、`input[type=number]` 原生 spinner、板块内"框包框"、卡片内再套卡片。

### 2.6 主题

每个模板必须同时提供**浅色**与**暗色**（`?theme=dark` 或 `[data-theme="dark"]`）两态，且暗色下**组件零改动自动适配**（令牌反转）。禁止在模板内写死浅色值。

### 2.7 装饰禁则（AI 味重灾区，违反即退回）

> **用户原话（2026-09-23）**：「我个人挺讨厌这种设计的，卡片左侧弄个色条，一眼就知道是 AI 随便搞的，一些设计和创意以及思考都没有」。
> 本条为**用户级禁令**，优先级等同 §2.1–§2.6，任何模板、任何页面均不得违反。

| # | 禁则 | 说明 |
|---|---|---|
| 1 | **禁止「卡片/行左侧彩色竖条」** | 无论用 `border-left` 还是 `box-shadow: inset`，一律禁止。它不承载任何语义，是对信息的**第二次冗余编码**，且是"没有设计思考"的最典型特征 |
| 2 | **同一信息只编码一次** | 状态 = `.dot`(8×8) + `.badge`（`b-ok/b-warn/b-err`），二选一或组合一次；产品（供应商）/ 厂商（生产公司）身份 = `.mark-sm` 首字或纯文字粗体（`.g-coding/.g-generic/.g-image`）。**不得**再叠一层颜色 |
| 3 | **禁止 hover 位移** | 无 `translateY/translateX`，hover 只允许 `background` → `--surface-muted` |
| 4 | **禁止装饰性阴影与渐变** | 阴影只能用 `--shadow-card` / `--shadow` / `--shadow-pop` 令牌；禁止手写 `rgba(...)` 阴影、渐变、玻璃拟态 |
| 5 | **禁止未兑现的风格宣称** | 注释里不得出现「Stripe 风格」「呼吸发光边」「极致专业度」等形容词——代码里没有实现就是空话 |

**唯一例外（v1.2 已废除）**：~~`.alert` 组件的左侧 3px 语义色边~~ —— 用户明确表态该样式也在厌恶之列（"为什么还有这种风格……项目内禁止允许使用这种样式"），**本禁令为全站绝对禁令，无任何例外**。`.alert` 已改为「1px 中性边框 + `--warn-bg/--err-bg/--cool-bg` 语义底色」承载语义（`base.css` §6 提示条已同步修改）。允许保留的只有**无色彩的中性 1px 结构分隔线**（如 `.matrix-table` 单元格分隔、`.timeline` 竖线）。

### 2.8 内容一致性（v1.5 新增，违反即退回）

> 触发：`template-vendor-accounts.html` 的账号面板有 16 行，但体检/用量面板各只有 9 行，且 7 处文案仍写「共 9 个账号」「全部通过 4 · 部分通过 2 · 失败 3（=9）」。**同一页内的数字自相矛盾**，是比样式错误更显眼的"低级错误"。

| # | 规则 |
|---|---|
| 1 | **同一份数据，只写一次**。面板行数、文案计数（`共 N 个账号`）、徽标聚合（`全部通过 X`）、指标值（`N 次调用`）**必须全部由同一份行数据推导**，禁止各处手写。 |
| 2 | **聚合值必须可复算**。凡出现 `X + Y + Z` 形式的徽标组，其和必须等于列表实际行数；凡出现「N 个账号合计」，其值必须等于各行该列之和。 |
| 3 | **占比列必须合计 100%**。用**最大余数法**分配，不得直接四舍五入（直接四舍五入实测会得 101%）。 |
| 4 | **扩数据必须同步扩全部引用点**。把 9 行扩到 16 行时，同页所有面板、文案、徽标、指标、loading/空态/toast 文案都要一起改；改完必须用脚本核对"文案数字 == DOM 实际数"。 |
| 5 | **跨面板顺序一致**。若同一实体出现在多个面板（账号列表 / 体检 / 用量），各面板的**行顺序必须一致**，便于横向比对。 |

**核对口径**：`共 N 个` 与实际 `data-row` 数比对；徽标组求和与行数比对；指标值与各行合计比对。三项全过才算达标（本轮已实现为自动检查）。

## 4. 页签体系（Tab System）—— 多页签页面怎么布局【重点】

> 这是本期最核心的新增能力。**六类页签全部复用同一个 `.tabs/.tab` 分段式组件**（frontend-spec §4.1），差异只在**容器、位置与行为**。设计时不得为某一类另造一套页签样式。

### 4.0 六类页签总表

| 编号 | 名称 | 位置 | 行为 | 是否入路由 | 典型用途 |
|---|---|---|---|---|---|
| **TB-1** | 分段视图 tab | 卡片外工具行 | 切换同页视图，面板 `hidden` 显隐 | 否（可选写 hash 查询） | 看板时段/维度、日志双 tab |
| **TB-2** | 工具行多组 tab | 同一行并排（gap 12） | 两组独立联动 | 否 | 看板「时段 × 维度」 |
| **TB-3** | **主从内页签** | 详情头卡**下方**、卡片堆叠**上方** | 切换详情子区；**写入 hash** | 是（`#/resources/res-xx/keys`） | 资源详情 / 模型详情 / 账号详情 |
| **TB-4** | **工作台页签条** | 顶栏（60px）**下方**、内容区**上方**，h-36 | 多对象并行：打开/关闭/固定/溢出折叠 | 是 | 同时看 5 个资源详情、跨页对照 |
| **TB-5** | 向导步骤条 | 向导卡**卡头** | 只前进/后退，不可跳步（已完成可回看） | 是（`?step=3`） | 接入向导、新增资源、授权接入 |
| **TB-6** | 锚点页签（吸顶） | 卡内**顶部吸顶** | 点击滚动到锚点；滚动联动高亮 | 否 | 长设置页、文档型长页 |

### 4.1 TB-1 / TB-2 分段视图 tab（已定版，本需求书只做约束）

- 沿用 frontend-spec §4.1：容器 `inline-flex gap-1 --radius-md(8) bg --seg-bg p-1`；段 `h-32 --radius-sm(6) px-3 12px/700 white-space:nowrap flex:none`（**标签禁换行**）；active 白底 + `--shadow` + 字 `--text`；非 active 字 `--text-tertiary`。
- 多组 tab 并排时**同一行** `flex-wrap gap-12 align-items:center`（v2.9 定版）。同行控件必须等高（§2.2）。
- 多组 tab 并排时**同一行** `flex-wrap gap-12 align-items:center`（v2.9 定版）。
- **反例**：两组 tab 上下两行；tab 加外框；active 用下划线而不用分段底。

### 4.2 TB-3 主从内页签（**新范式，重点设计**）

**布局（自上而下）**：

```
┌ 内容区（p-3 全宽）──────────────────────────────────────────────┐
│ 头卡（.card）：logo-block 40 + 名称 15/800 + 副行 12/600 faint   │
│                右侧 [启停 .btn] [删除 .icon-btn.lg.danger]        │
├ 页签行（.card 内 或 卡外工具行 · mb-12）──────────────────────────┤
│ [ 概览 ][ 密钥与账号 ][ 模型映射 ][ 连通性 ][ 用量 ]              │  ← TB-3
├ 页签面板（.card 堆叠 · space-y-3）───────────────────────────────┤
│ 当前页签的卡片组（1–4 张卡）                                     │
└─────────────────────────────────────────────────────────────────┘
```

**硬性规格**：

| 项 | 值 |
|---|---|
| 页签行位置 | 头卡**下方**，`mt-3`（12px）；页签行与面板之间 `mb-3`（12px） |
| 页签行容器 | 复用 `.tabs`（分段式，rounded-11 `--seg-bg` p-1）；**全宽左对齐**，右侧可挂该页签级操作（`.page-actions`） |
| 段数量 | 3–6 个；超过 6 个必须合并或降级为 TB-4 |
| 段文案 | 2–4 个汉字（如「密钥与账号」最多 5 字）；**禁止图标 + 文字混排**（图标留给 TB-4） |
| 路由 | `#/<page>/<objectId>/<tabKey>`；**刷新后停留在同一页签**；深链可直接打开 |
| 切换行为 | 面板显隐（`hidden`），**不重新请求头卡数据**；每个页签数据懒加载（首次进入才拉） |
| 徽章 | 允许在段文案后挂**计数徽章**（如「模型映射 12」），用 `11px/700` 数字 + 4px gap，不用圆点 |
| 禁用态 | 该页签不适用时（如 images 模型无「参数」页签）**整段隐藏**，不置灰（避免用户困惑"为什么不能点"） |

**必须在设计稿中体现的 3 个细节**：① 页签行与头卡的间距（12px）；② 页签切换时面板顶部**不发生跳动**（面板高度可不同，但页签行位置固定）；③ 暗色下 active 段的白底→深底反转。

### 4.3 TB-4 工作台页签条（TagsView，**新范式，重点设计**）

**什么时候用**：需要**并行打开多个同类对象**（如同时看 5 个资源的连通性、对照 2 个模型的参数）。**7 个顶层页面本身不用它**——顶层页面继续走侧栏导航，避免"侧栏 + 页签条"两套导航互相打架。

**布局**：

```
┌ 顶栏 60px（面包屑 + 页标题）───────────────────── [主题组][重载] ┐
├ 页签条 h-36（.tabbar · 白底 · border-b · px-12 · gap-4）─────────┤
│ [● 模型资源] [资源:商汤按量 Key1 ×] [资源:DeepSeek 主 ×] [模型:… ×] [⋯]│
├ 内容区（p-3）───────────────────────────────────────────────────┤
│ 当前激活页签的页面内容                                          │
└─────────────────────────────────────────────────────────────────┘
```

**硬性规格**：

| 项 | 值 |
|---|---|
| 条高 | **36px**；白底（暗色 `--surface`）；下边框 `--border`；`padding 0 12px`；`gap 4px`；横向滚动条**隐藏** |
| 页签项 `.tabbar-item` | **h-28 rounded-9 px-3** 13px/600；结构 = `图标 14 + 标题(截断, max-width 180px) + 关闭 ×14`；间距 4px |
| active 态 | 白底（暗色 `--surface-muted`）+ `--shadow` + 字 `--text`（与 TB-1 active 同语义）；非 active 字 `--text-tertiary`，hover bg `--side-hover` |
| 图标 | 用该页面的 Lucide 图标（14px）；**详情对象页签**用对象的 mark 首字（20×20 rounded-6）替代图标，以区分同类多开 |
| 关闭钮 | `×` 14px；hover 变 `--err`；**固定态隐藏关闭钮**，图标位改 `pin`（16px） |
| 固定（pin） | 右键菜单或悬停显示 pin 图标；固定页签**排在最左**、不可关闭、不可拖出 |
| 溢出 | 超过可视宽度：右侧固定 `.tabbar-more`（`⋯` 32×32 icon-btn）→ 下拉列出未显示页签（可点击跳转 + 关闭） |
| 上限 | 默认 **8 个**（固定页签不计入）；达上限时 toast 提示「页签已达上限，请先关闭」 |
| 关闭当前 | 激活**右邻**；无右邻则激活**左邻**；全部关闭则回落到该页签的父级页面 |
| 首项 | 每个一级页面固定一个**不可关闭**的页签（如「模型资源」）；详情对象页签可关闭 |
| 持久化 | 页签集合与激活项写 `sessionStorage`（**刷新保持、关浏览器清空**），不写 `localStorage` |
| 空态 | 只有一级页面页签时，页签条**仍然显示**（保持布局稳定），不隐藏 |

**与 TB-3 的关系**：TB-4 是"多个对象"，TB-3 是"一个对象内的多个视图"。**允许嵌套**：页签条上打开 3 个资源详情，每个详情内部各有 5 个 TB-3 页签。设计稿需给出这个嵌套态的示意图。

**反例**：页签条做成 40px 高（与顶栏争夺视觉权重）；页签项带彩色底（应统一中性）；关闭钮常显（应 hover 显示或低对比常显）。

### 4.4 TB-5 向导步骤条

```
┌ 向导卡 .card（max-width 720 居中 或 全宽）──────────────────────┐
│ ① 选择宿主 ──── ② 填写地址 ──── ③ 选择模型 ──── ④ 验证 ──── ⑤ 完成 │  ← 步骤条
├─────────────────────────────────────────────────────────────────┤
│ 当前步骤内容（表单 / 列表 / 代码块 / 结果）                      │
├─────────────────────────────────────────────────────────────────┤
│                                   [上一步 .btn] [下一步 .btn-primary] │
└─────────────────────────────────────────────────────────────────┘
```

| 项 | 值 |
|---|---|
| 步骤条 | 横向；节点 = 序号圆（**24×24 rounded-full**，完成态 `--brand` 底反白 + `check` 图标；当前态白底 + `2px --brand` 描边；未来态 `--seg-bg` 底 + `--text-faint` 序号）+ 连接线（1px `--border`，完成段 `--brand`）+ 步骤名（12px/600，当前 `--text`、其余 `--text-tertiary`） |
| 步骤数 | 3–5 步；超过 5 步重新拆分任务 |
| 步进 | 只允许「上一步 / 下一步」；已完成步骤可点击回看（但改值后需重新验证后续步骤） |
| 校验 | 「下一步」按钮在必填未完成时 `disabled`（`opacity .45`），并在字段下方给行内错误提示 |
| 退出 | 右上角 `×` 关闭 → 若有未保存内容弹确认；退出后草稿**不落库**（符合既有"草稿槽位唯一"范式） |
| 路由 | `?step=N`，刷新保持在当前步 |
| 完成态 | 末步不显示「下一步」，改显示**结果卡**（成功/失败 + 后续动作按钮） |

### 4.5 TB-6 锚点页签（吸顶）

| 项 | 值 |
|---|---|
| 位置 | 内容区顶部 `sticky top:0`，背景 `--content` + 底部 1px `--border`（滚动时才出现，避免静态时多一条线） |
| 形态 | 复用 `.tabs` 分段式，但**点击是滚动而非显隐** |
| 高亮 | 由 `IntersectionObserver` 联动；高亮段随滚动自动切换 |
| 适用 | 单页内容高度 > 2 屏的长设置页 / 说明页；**短页禁止使用**（徒增噪音） |

### 4.6 选型决策规则（设计时先过这张表）

| 你的场景 | 选 |
|---|---|
| 同一对象、同一层级、视图互斥（流水 / 事件） | TB-1 |
| 两个维度同时筛选（时段 × 维度） | TB-2 |
| 一个对象的多个**子域**（概览/密钥/映射/用量） | **TB-3** |
| 同时打开多个**同类对象** | **TB-4** |
| 多步流程、有先后依赖 | **TB-5** |
| 单页很长、需要快速定位 | TB-6 |
| 只是想切换两个列表的排序/筛选 | **都不用**（用筛选控件，不是页签） |
